# 500개 종목 재무 수치 재검토

검토일: 2026-10-10. 개발 사이트 데이터에 대한 수치·출처 대조입니다. 기업 설명·용어·디자인은 변경하지 않았습니다.

- 범위: 500개 종목, 477개 발행사, 본주 실적을 공유하는 우선주 23개. 저장된 연간·분기 2,410개 기간 자료의 표시 수치 5,637항목을 확인했습니다. 첫 정기보고서 대기 중인 한화머시너리앤서비스홀딩스에는 수치를 생성하지 않았습니다.
- 자동 대상의 일반 결산 수치 5,276항목은 새로 받은 공식 OpenDART 재무제표와 대조했습니다. 최신 사업·반기보고서의 과거 비교 값과 3개월·누적 값을 구분했습니다. 최신 API가 비교 항목을 생략한 3개 기간은 원 기간 공시로 확인했습니다.
- 특수 결산·통화·수동 확인 수치 261항목은 DART 손익계산서 원문과 실제 기간 또는 공식 API로 대조했습니다. 6개월·3개월 결산 리츠, 11월·3월 결산, USD, 합산·차감한 기간을 별도 확인했습니다.
- 기존 IR 기반 표시 수치 100항목은 공식 회사 IR·감사보고서·보도자료와 대조했습니다. 이 중 우리금융·삼성생명·삼성화재의 일반 회계 지표 26항목은 DART 기준으로 다시 확인해 반영했습니다. 인프라 펀드의 평가손익 제외·회계상 지표, 금융사의 회사 고유 IR 지표, 두산밥캣의 원화 보도자료는 해당 정의와 통화를 유지합니다.
- 공식 API 수집 파일 1,000건을 확보했습니다. 금양의 2026년 반기 API는 자료 없음(013)을 반환하므로 기존에 표시하지 않던 해당 기간 수치를 추가하지 않았습니다.
- 28개 발행사의 46개 기간 자료를 갱신했고, 총 87개 숫자가 달라졌습니다. 잠정·확정 차이, 최신 공시의 재분류·비교값, 지표 불일치 교정 및 원 단위 정밀도 보완을 포함합니다.
- 우리금융의 순이자이익 자리에 들어 있던 순영업수익 숫자를 교정했습니다. 예: 2025년 10.957조 → 순이자이익 9.030769조. 삼성생명·삼성화재는 IR의 조정·잠정 값과 DART 연결재무제표 값을 구분해 표시 지표를 맞췄습니다.
- 최신 비교표의 반올림으로 미세한 차이가 난 8개 항목은 원 공시의 더 정밀한 값과 일치함을 확인하고 유지했습니다.
- 최신 보고서의 비교·재분류 값을 원 기간 API가 덮어쓰지 않도록 관련 기간 자동 반영을 보류했습니다. 기존 수동 확인 발행사는 수동 모드를 유지합니다.
- 원 단위 금액과 조 단위 저장 값, 손익 부호, 연결·별도, 통화, 실제 기간, 우선주 연결 및 출처 참조를 검사했습니다. 자동 대상 444개 발행사의 2,046개 실제 API 보고서 재실행에서 중복·되돌림 변경이 발생하지 않았습니다.

이는 공개된 공식 자료와 사이트 데이터의 일치 검토이며 회계감사 의견을 의미하지 않습니다. 향후 정정·재분류 공시로 비교 수치가 바뀔 수 있습니다.
