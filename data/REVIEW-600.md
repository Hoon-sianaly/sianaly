# 600개 종목 확장 검토

기준일: 2026-10-13. 기존 550개 종목을 보존하고 조회 시점 코스피 시가총액 순서에서 미등록 50개 종목을 추가했습니다. 현재의 정확한 상위 600개 명단과는 차이가 있을 수 있습니다.

## 조사·대조 방법

- 10개씩 5묶음으로 사업 설명과 수치를 대조한 후 다음 묶음으로 진행했습니다.
- 새 발행사 46곳의 DART 회사 정보와 종목코드를 확인하고, 사업의 내용·손익계산서·감사 관련 항목을 읽었습니다.
- 소개 5줄, 주요 사업, 실적을 좌우하는 요인, 본문에 등장하는 어려운 용어와 공식 출처를 작성했습니다.
- 공식 손익계산서에서 표시한 원·천원·백만원 단위를 구분하고, 연결·별도 범위와 실제 기간을 확인했습니다.
- 최신 보고서의 과거 비교값이 달라진 경우 최신 값을 반영하고, 과거 API 재수집으로 되돌아가지 않도록 해당 기간을 보류했습니다.
- 신규 표시 수치 558개를 원문과 대조했습니다. 묶음별 대조 수는 84·106·126·120·122개이며 미해결 숫자 불일치는 없습니다. 원문 반올림 단위에 따른 허용오차는 단일 값 1단위, 차감 값 2단위입니다.
- CJ우, CJ제일제당 우, 금호석유화학우, 미래에셋증권우는 해당 본주 회사 전체 실적을 공유하며 우선주만의 매출로 표시하지 않습니다.

## 개별 검토

- 만호제강: 실제 6월 결산입니다. 최근 12개월 결산과 비교기간을 동일한 별도 범위로 맞췄고, API 누락 분기는 원문으로 확인했습니다. 4~6월은 연간 값에서 직전 9개월을 원 단위로 차감했습니다. 자동 수치 반영은 수동 검토 대상으로 유지합니다.
- 이지스레지던스리츠: 6월·12월 종료 6개월 결산입니다. 최신 정정 보고서의 2026년 1~6월과 2025년 1~6월을 비교하고 실제 달력 3개월을 별도로 표시했습니다. 회계상 영업수익·순이익과 배당 재원을 구분합니다. 수동 검토 대상으로 유지합니다.
- 와이투솔루션: API에서 누락된 과거 연간·분기 값은 최신 보고서의 비교값으로 보충하고 원 기간 재수집을 보류했습니다.
- 동성제약: 2025년 재무제표 감사 적정과 내부회계관리제도 감사 부적정을 구분해 설명했습니다. 내부통제 관련 공시를 확인하고 수동 반영 대상으로 유지합니다.
- DKME: 2025년 재무제표 감사 적정, 내부회계관리제도 감사 부적정과 상장폐지 사유·개선기간 관련 강조사항을 구분해 설명했습니다. 수동 반영 대상으로 유지합니다.

## 전체 상태

600개 종목, 발행사 571곳, 본주 실적 공유 종목 29개입니다. 자동 반영 발행사 531곳, 공식 공시 수동 확인 발행사 40곳입니다. 자동 대상에도 과거 비교값 보호를 위한 기간별 보류가 있을 수 있습니다. 상세 사유는 DART-STATUS.md에 기록합니다.

기존 550개 회사 자료를 파일 단위로 대조해 내용이 바뀌지 않았음을 확인했습니다. 연결 기준 용어를 화면에서 숨기는 정책과 기존 그래프·검색 기능을 유지합니다.
