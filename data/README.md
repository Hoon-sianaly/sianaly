## 파일 구성

- `company-index.json`: 기업 키·이름·종목코드·데이터 파일 목록. 기업 분석 페이지는 이 목록에 등록된 기업만 읽습니다.
- `companies/samsung.json`: 기업 정보, 5줄 소개, 주요 사업, 핵심 변수, 실적, 출처, 용어 설명.
- `companies/samsungpref.json`: 우선주 설명·시세는 별도로 관리하고 회사 실적은 `financials.companyRef: "samsung"`으로 참조합니다.

홈페이지 검색·기업 목록과 기업 상세 페이지는 `company-index.json` 목록을 공유합니다. 기업명·종목코드·`alias`의 별칭을 검색하며, 공백과 영문 대소문자는 구분하지 않습니다. 최근 본 기업은 이 브라우저의 `sianalyRecent` 저장값을 공유하며 등록된 종목만 표시합니다.

## 실적과 출처

- 숫자는 조원(`KRW_trillion`)으로 저장합니다. 예: 1억원은 0.0001조원입니다.
- 연간은 `year`, 분기는 `year`와 `quarter`(1~4)를 사용합니다. 분기 수치는 각 3개월 실적이며 누적 실적을 넣지 않습니다.
- `basis`는 `consolidated`(연결) 또는 `separate`(별도)입니다. 한 데이터 묶음에서 기준을 섞지 않습니다.
- `sourceIds`는 해당 숫자를 확인한 `sources[].id`를 가리킵니다. 출처에는 문서명·공식 URL·발표일·확인일을 기록합니다. 발표일이 없는 상시 재무정보 페이지는 발표일을 추정하지 않고 `asOf`에 자료 기준을 기록합니다.
- `verification.status`의 `verified`는 원자료와 대조를 마친 자료에만 사용합니다. 등록된 300개 종목의 표시 수치는 공식 자료와 대조했습니다. 삼성전자우·현대차2우B의 회사 실적은 각각 삼성전자·현대자동차 자료를 공유합니다. 검증 표시는 최신 공시 전체를 수집했다는 의미가 아니며, 페이지에 표시한 실적 기간과 설명을 함께 확인합니다.
- `financials.metrics`는 차트·표·상단에 표시할 지표 이름과 설명입니다. 은행은 금융 비용을 상계한 IR 지표, 생명보험은 보험서비스손익·지배주주 순이익, 손해보험은 보험수익·영업이익을 사용합니다. 제조업 매출과 같은 지표로 해석하지 않도록 화면에 설명합니다.
- 확인되지 않은 숫자를 추정해서 넣지 않습니다. 새 기업의 실적과 설명을 준비하고 검증한 뒤 검색 목록에 등록합니다.
- 상단 연간 실적은 가장 최근 연간 행에서 자동으로 계산합니다. 분기 영역은 저장된 분기 중 가장 최근 연도의 실적을 표시합니다. 지난 연도 행도 JSON에는 보관할 수 있습니다.
- 화면의 금액은 절댓값 1조원 이상이면 조원(소수 둘째 자리까지), 1억원 이상이면 억원, 1만원 이상이면 만원, 그 이하면 원으로 표시합니다. 억원 이하 단위는 정수로 반올림하며 음수 부호를 유지합니다. 표와 요약·그래프 막대에는 금액마다 단위를 표시합니다. 각 그래프의 눈금은 해당 지표의 최대 절댓값으로 단위를 정하고 그 단위를 명시합니다. 숫자 원본은 항상 조원으로 저장합니다. 기존 `highlightFormat`·`tableNumbersOnly` 설정과 관계없이 동일한 금액 표시 규칙을 사용합니다.
- `presentation`은 기존 화면 유지용 설정입니다. 기존 삼성전자 화면은 `compact: true`, `chartStyle: "comparison"`을 사용합니다.

   - 삼성전자와 동일하게 5줄 소개·주요 사업·핵심 변수·실적·출처·용어 설명을 한 묶음으로 검토합니다. 용어 설명을 후순위로 미루지 않습니다.

3. `node scripts/validate-data.cjs`, `node scripts/test-glossary.cjs`, `node scripts/test-company-data.cjs`, `node scripts/test-search.cjs`, `node scripts/test-insights.cjs`, `node scripts/test-financial-format.cjs`를 실행합니다.
4. 데이터 파일을 바꿨다면 `company-data.js`의 `COMPANY_DATA_VERSION`과 `company.html`·`index.html`의 스크립트 버전을 함께 올립니다. 캐시로 서로 다른 버전이 섞이는 것을 방지합니다.

## 배포

현재 Cloudflare Pages의 `sianaly` 프로젝트는 `main` 브랜치를 자동 배포하며 연결된 도메인은 `dev.sianaly.com`입니다. `sianaly.com`은 운영용입니다. 운영 사이트 반영은 사용자가 별도로 요청한 경우에만 진행합니다.

기존 `companies.js`는 캐시된 이전 화면을 위한 호환 파일입니다. 새 데이터의 원본은 JSON 파일이며 이 호환 파일에는 새 기업을 추가하지 않습니다.

SK스퀘어의 2024년 수치는 2025년 감사보고서의 중단사업 분리 후 재작성 수치입니다. 2023년은 당시 발표 기준이므로 연간 집계 범위 차이를 화면에 설명합니다. 지분법 이익을 제품 판매 이익률로 해석하지 않도록 별도 안내합니다.

실적 요약은 최신 연간·분기 행의 원본 수치로 계산합니다. 연간 증감은 직전 연도, 분기는 전년 동기 자료가 있으면 전년 동기와 비교하며 없으면 직전 분기와 비교하고 기준을 표시합니다. 연속된 비교 기간이 없으면 비교 자료 없음으로 표시합니다. 이익은 흑자·적자 전환과 적자 확대·축소를 별도 문구로 표시하며 0을 기준으로 증감률을 계산하지 않습니다. 영업이익률은 지표가 매출·영업이익인 경우에만 표시합니다. 금융·보험 등 다른 지표 조합에는 표시하지 않습니다. 최신 실적 기간과 원자료 확인일은 상단에 모아 표시합니다.
