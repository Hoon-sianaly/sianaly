# 신규 50개 종목 검토 기록

기준일: 2026-10-13. 개발 사이트를 500개에서 550개 종목으로 확대합니다.

- 기존 500개 기업 파일은 그대로 보존하고, 현재 코스피 시가총액 순서에서 미등록 상위 50개 종목을 추가했습니다. 주가 변동 때문에 기존 목록을 보존한 550개와 현재 정확한 시총 상위 550개가 일부 다를 수 있습니다.
- 신규 발행사 48개, 본주 재무 실적을 공유하는 우선주 2개입니다. 전체 550종목·525발행사 중 자동 대상 489개, 공식 자료 수동 확인 대상 36개, 실적 공유 우선주 25개입니다.
- 신규 발행사의 공식 기업정보와 종목코드를 대조하고, 사업의 내용과 회계감사인 의견 관련 자료를 수집했습니다. 기업별 5줄 소개, 사업, 실적 요인과 본문 용어를 작성했습니다. 우선주는 본주의 사업·실적과 종목별 권리를 구분합니다.
- 신규 표시 수치 584항목을 공식 손익계산서 원문과 대조했습니다. 원·천원 단위, 손익 부호, 연결·별도, 3개월·누적값 및 최신 재분류 비교값을 구분했습니다.
- AJ네트웍스·계룡건설·HS효성·DH오토넥스 등의 최신 비교값과 동성케미컬의 변경 비교값을 반영했습니다. 원 기간 API가 과거 수치로 되돌리지 않도록 해당 기간 자동 반영을 보류합니다.
- 방림의 9월 결산과 최신 회계 3분기(2026년 4~6월)를 실제 날짜로 표시합니다. 디앤디플랫폼리츠·NH올원리츠의 6개월 결산은 전년의 같은 기간과 비교하고, 실제 3개월은 공시 원문 또는 원 단위 차감으로 확인했습니다.
- HS효성의 2024년 첫 결산은 6개월이며 2025년은 12개월입니다. 해당 연간 증감률을 표시하지 않고 실제 기간을 밝힙니다. 공시상 매출액 및 지분법손익도 일반 매출과 구분합니다.
- 동국씨엠의 2024년 API 누락 수치는 최신 공식 비교표로 확인했습니다. 아주스틸 편입으로 연결 범위가 달라진 점과 종속회사 내부회계관리제도의 과거 부적정 의견을 모회사 재무제표 의견과 구분합니다. 동부건설은 인천 검단 현장 사고 관련 감사 강조사항을 연결합니다.
- 검색·출처·재무 형식·자동 업데이트·기간 비교 검사와 550개 상세 화면의 320px 모바일 검사를 수행했습니다. 기존에 요청한 ‘연결 기준’ 용어 숨김 정책을 유지합니다.

자료 대조는 회계감사 의견이나 앞으로 정정이 없다는 보증을 의미하지 않습니다. 특수 결산 회사와 자동 반영 보류 기간은 후속 공시가 나오면 별도로 확인합니다.
