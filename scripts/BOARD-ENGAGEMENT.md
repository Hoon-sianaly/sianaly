# 커뮤니티 추천·조회수

2026-11-07 요청. 사용자가 핵심 기능 최종 점검을 완료했다고 확인한 뒤 추가.

- 목록·글 상세에 추천과 조회수 표시. 댓글에는 집계 표시 없음.
- 추천은 검증된 로그인 회원마다 글당 한 번. 다시 누르면 취소. 요청은 원하는 상태를 보내므로 중복 전송·동시 재시도로 중복 증가하지 않음. 본인 글 추천도 허용.
- 조회수는 글 상세를 열 때만 같은 출처의 JSON POST로 집계. GET·목록·댓글 추가 페이지 조회는 증가시키지 않음.
- 로그인 회원은 회원별, 비로그인 방문자는 브라우저 쿠키별로 동일 글을 30분 이내 다시 열면 집계하지 않음. 조회수는 방문자 수나 본인확인 수치가 아니며, 다른 브라우저·쿠키 삭제·로그인 전후 등은 별도 집계될 수 있음.
- 방문 쿠키는 90일 Secure/HttpOnly/SameSite=Lax(개발 localhost만 Secure 예외). 원 IP나 이메일을 조회 테이블에 저장하지 않음. 저장소에는 해시 식별자만 저장. 중복 방지 기록은 24시간 이후 다음 조회 요청에서 정리하며 누적 조회수는 유지.
- 추천자의 회원 구분값도 해시 저장. 회원 탈퇴 동기화 때 해당 추천과 회원 조회 중복 방지 기록을 삭제. 게시물과 누적 조회수는 유지.
- 숨긴 글에는 조회 집계·추천 불가. 글 삭제 시 관련 추천·조회 기록·집계 데이터 함께 삭제.
- 기존 글·댓글을 변경하지 않는 D1 추가 테이블/인덱스/트리거를 IF NOT EXISTS로 초기화. 조회수는 적용 시점부터 0으로 집계하며 과거 값을 추정하지 않음. 서버는 조회 기록 INSERT/조건부 UPDATE 트리거로 중복 집계와 카운터 갱신을 한 트랜잭션에서 처리.
- 새 테이블: board_recommendations, board_post_stats, board_view_visitors. 기존 POPULAR_DB 사용. Supabase 테이블·정책 변경 없음.

검증: scripts/test-member-account.mjs에서 추천 회원 격리·중복/동시 요청·취소·익명 거부·본문 소유자 위조 거부, 조회 쿠키·30분 재조회·회원 중복 방지·GET 무집계·CSRF·숨김/삭제/탈퇴 정리를 실제 SQLite로 검증. scripts/test-member-rls.mjs 및 scripts/test-company-reports.mjs 회귀 검사.

개인정보 처리방침을 확정할 때 방문 중복 방지 쿠키와 위 보유·삭제 동작도 포함할 것.
