# SIANALY 모바일 앱 계획안

작성: 2026-11-16 · 상태: **조사·제안** ([전면 개편 계획안](REBUILD-PLAN-20261116.md)이 끝난 뒤를 전제로 함)

## 한 줄 요약

개편으로 기업 자료가 **데이터베이스 하나 + 서울 서버**로 모이면, 앱은 그 자료를 같이 쓰기만 하면 돼요. 그래서 앱을 따로 처음부터 만들 필요가 없어요. 순서는 이렇게 추천해요.

1. **설치형 웹앱**(며칠, 무료)
2. **Expo로 만드는 스토어 앱**(주요 화면은 앱 전용, 나머지는 웹 화면 재사용, 실적 알림이 핵심 기능)

---

## 1. 왜 개편 뒤에 하는 게 좋은가

- 지금 구조에서 앱을 만들면 앱도 미국 서버를 거쳐서 똑같이 느려요.
- 지금은 자료가 파일 2,800여 개로 흩어져 있어요. 앱이 "삼성전자 실적 주세요"라고 한 번에 물어볼 곳이 없어요.
- 개편 뒤에는 서버에 **"기업 정보 주세요", "즐겨찾기 주세요" 같은 창구**가 생겨요. 웹과 앱이 같은 창구를 쓰니, 웹을 고치면 앱도 같이 좋아져요.

---

## 2. 앱을 만드는 방법 세 가지

| 방법 | 설명 | 작업량 | 스토어 | 위험 |
|---|---|---|---|---|
| A. 설치형 웹앱 | 사이트를 휴대폰 홈 화면에 설치. 아이콘이 생기고 주소창 없이 열림. 알림도 가능 (아이폰은 홈 화면에 설치한 경우만) | 며칠 | 안 올라감 | 거의 없음 |
| B. 웹을 감싼 앱 (Capacitor) | 사이트를 앱 껍데기에 넣고 알림·공유 등 몇 가지만 앱 기능으로 추가 | 2~4주 | 올라감 | 애플이 "웹사이트를 감싼 것뿐"이라며 거절하는 경우가 잦음 (심사 지침 4.2) |
| C. Expo(리액트 네이티브) 앱 | 자주 쓰는 화면을 앱 전용으로 만들고, 덜 쓰는 화면은 웹 화면을 재사용 | 4~8주 | 올라감 | 거절 위험 낮음. 할 일은 가장 많음 |

### 추천: A로 먼저 시작하고, 그다음 C

- **윈도우 컴퓨터로도 아이폰 앱을 만들 수 있어요.** Expo는 아이폰 앱을 인터넷(클라우드)에서 대신 만들어 줘요. 무료 요금제로도 한 달에 아이폰·안드로이드 각 15번까지 만들 수 있어요. B 방법은 보통 맥(Mac)이나 별도 유료 빌드 서비스가 필요해요.
- **애플 심사에 유리해요.** 앱 전용 화면, 알림, 홈 화면 위젯 같은 기능이 있으면 "웹사이트를 감싼 것뿐"이라는 이유로 거절될 일이 줄어요.
- **개편한 서버와 데이터베이스를 그대로 써요.** 회원 로그인(Supabase)도 앱에서 그대로 쓸 수 있어요.

---

## 3. 앱에 넣을 것 (C 기준 1차 버전)

| 화면·기능 | 만드는 방식 |
|---|---|
| 홈: 검색, 지금 많이 보는 기업, 공시 요약 | 앱 전용 |
| 기업 요약: 한눈에 보기, 최근 실적, 증감 | 앱 전용 |
| 기업 자세히: 사업, 연도별 차트, 핵심 변수 | 처음엔 웹 화면 재사용, 나중에 앱 전용으로 |
| 즐겨찾기 | 앱 전용 |
| **즐겨찾기 기업 실적 알림** | 앱 전용 (핵심 기능). DART 자동 업데이트가 반영할 때 그 기업을 즐겨찾기한 회원에게 알림 |
| 비교 | 웹 화면 재사용 |
| 자유게시판 | 웹 화면 재사용 |
| 로그인·회원가입·탈퇴 | 앱 전용. 애플은 앱 안에서 탈퇴할 수 있어야 함 (지금 마이페이지 탈퇴 기능을 앱에도) |
| 처리방침·약관·자료 안내 | 웹 화면 재사용 |

## 4. 스토어에 올릴 때 꼭 알아야 할 것

### 구글 플레이
- 가입비 **$25 (한 번)**.
- **개인 계정이면 정식 출시 전에 테스트를 꼭 거쳐야 해요.** 2023년 11월 이후 만든 개인 계정은 **12명 이상이 14일 동안 계속 테스트**해야 정식 출시를 신청할 수 있어요. 14일을 채워도 승인이 자동으로 나지는 않아요.
  - 대안: 사업자(조직) 계정은 이 규칙이 보통 면제돼요. 대신 D-U-N-S 번호 발급에 최대 30일 정도 걸릴 수 있어요.
  - 사장님의 '처음 방문하는 사람 반응 확인' 계획(친구 몇 명)과 합치면 테스트 인원 12명을 같이 해결할 수 있어요.

### 애플 앱스토어
- 개발자 등록비 **매년 $99**.
- **심사 지침 4.2:** 웹사이트를 감싸기만 한 앱은 거절될 수 있어요. 그래서 앱 전용 화면과 알림을 넣어요.
- 앱에서 가입할 수 있으면 **앱 안에서 탈퇴도 가능해야** 해요.
- **소셜 로그인:** 지금처럼 이메일 로그인만 쓰면 "Apple로 로그인"을 꼭 넣을 필요는 없어요. 나중에 카카오·네이버·구글 로그인을 열면 함께 넣어야 할 수 있어요.
- 스토어에 개인정보 항목(무엇을 모으는지)을 입력해야 해요.

### 한국 법·문서
- **앱 접근권한 안내:** 알림 같은 휴대폰 기능을 쓰면 무엇을 왜 쓰는지 안내해야 해요 (정보통신망법).
- **개인정보처리방침 개정:** 알림을 보내려면 기기 알림 식별값을 새로 모아야 해서, 수집 항목에 추가하고 새 버전을 내야 해요.
- **투자 유의 문구:** 웹처럼 앱에서도 "참고용 정보이며 투자 권유가 아님"을 보여 줘요.

## 5. 비용

| 항목 | 금액 |
|---|---|
| 구글 플레이 | $25 (한 번) |
| 애플 개발자 | $99 / 년 |
| Expo 빌드 | 무료 (한 달 각 15번) → 많아지면 월 $19부터 |
| 알림 발송 | 무료 범위 (Expo 알림 서비스, 구글·애플 알림) |

요금과 스토어 규칙은 자주 바뀌어요. 시작할 때 다시 확인할게요.

## 6. 진행 순서 (개편 완료 뒤)

| 단계 | 내용 | 기간(예상) | 하는 사람 |
|---|---|---|---|
| 1 | 설치형 웹앱: 앱 아이콘, 설치 안내, 오프라인 안내 화면 | 며칠 | 에이전트 |
| 2 | 앱용 창구(API) 정리: 기업 요약, 즐겨찾기, 알림 등록 | 1주 | 에이전트 |
| 3 | Expo 앱 1차 화면과 로그인 | 2~3주 | 에이전트 |
| 4 | 실적 알림: DART 업데이트와 연결 + 처리방침 개정 | 1주 | 에이전트, 사장님 확인 |
| 5 | 구글·애플 개발자 계정 만들기, 스토어 설명·스크린샷 | 함께 | 사장님 (문구는 에이전트가 준비) |
| 6 | 구글 비공개 테스트 12명 × 14일, 애플 TestFlight 테스트 | 2주 이상 | 사장님(테스터 모집), 에이전트(수정) |
| 7 | 정식 출시 신청과 심사 대응 | 며칠~2주 | 함께 |

**전체:** 개편이 끝난 뒤 약 6~10주. 구글 14일 테스트와 심사 기간이 포함돼요.

---

## 7. 정해 주실 것

1. 설치형 웹앱부터 할지, 바로 스토어 앱으로 갈지
2. 구글 계정: 개인으로 할지(12명 테스트 필요), 사업자로 할지
3. 알림 기능 넣기 (넣으면 처리방침 개정 필요)
4. 1차 버전에서 앱 전용으로 만들 화면 범위
