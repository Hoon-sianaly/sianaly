## 판정과 범위

기업 재무 데이터는 사용자 요청으로 제외. 개인정보 처리방침·이용약관·가입 안내를 현재 서버/브라우저 코드, 개발 사이트 응답, Supabase의 집계·권한 조회, 기존 외부 설정 확인 기록, 최신 공식 안내서와 대조했다. 회원 본문·비밀번호·메일 링크·사진 값은 보고서에 수집하지 않았다.

**대조 작업은 완료했으나 공개 가입 준비 완료 판정은 보류.** 국외 처리 고지·근거와 운영자 접속기록의 실제 보관 체계를 먼저 마무리해야 한다. 백업 만료·삭제 요청 재적용은 구현/절차/실행 여부를 구별해야 한다. 이 문서는 법률 적합성 인증이나 모든 보안 취약점 부재의 보증이 아니다.

현재 시행 묶음은 `2026-11-08-r3`. `legal/2026-11-09/`는 로컬 대조 초안이며 시행일 미정이다. 서버 동의 버전을 미리 변경하거나 기존 회원에게 초안 동의를 소급 생성하지 않았다. 기존 보관본은 변경하지 않았다.

## 공개 전 남은 조치와 순서

### 1. 운영자 접속기록을 실제로 보관할 구성 확정

2026.11 안전성 확보조치 기준 안내서 제8조는 정보주체 본인의 접속과 별개로 개인정보시스템 취급자의 접속기록을 최소 1년 보관하도록 설명한다. 특정 규모·정보 종류 등은 2년 대상. 소규모 운영자의 내부관리계획 생략 예외를 모든 접속기록 면제로 해석하면 안 된다.

- 현재 Supabase 무료 표준 로그 1일과 회원 Auth 로그는 이 요구를 충족했다는 증거가 아니다.
- 사이트 관리 화면의 개인정보 조회/처리, 공급업체 대시보드·SQL·다운로드·백업의 행위 기록을 각각 확인해야 한다.
- 취급자 식별자·시각·접속지·처리 대상 식별·업무를 최소 항목으로 남기고, 본문/비밀번호/인증 링크는 로그에 복제하지 않는다.
- 최소 보관·접근 제한·변조 방지·별도 보관/무결성·정기 점검 경로를 함께 정해야 한다. 보고서 작성이나 수기 대장만으로 자동 접속기록 의무가 충족됐다고 하지 않는다.
- 이번에는 새 운영자 감사 저장소를 배포하지 않았다. 무료 제공 기능으로 부족하면 필요한 구성과 비용을 비교한 뒤 선택한다.

### 2. 국외 처리 항목별 근거·고지 완결

- 서울 DB·도쿄 메일 발송은 모든 정보의 국내/일본 처리 보장이 아님.
- D1의 APAC/관할 제한 없음은 국가 확정 정보가 아님. 글로벌 지원·내부 기록·하위 처리자의 유형별 국가/기간과 별도 구분.
- 계약 이행에 필요한 위탁·보관에 적용하는 근거를 Turnstile 자체 탐지 개선이나 모든 비회원 요청에 일괄 적용해 확정하지 않는다. 처리 관계와 법적 근거를 유형별로 정리해야 함.
- Gmail 문의 수신·회신도 해외 처리 검토 범위. 단순히 ‘글로벌 인프라’라고 적는 것만으로 완결됐다고 판단하지 않음.
- 공식 계약·문서·실제 설정으로 충분하면 업체에 메일을 보내는 행위 자체는 필수 아님. 부족한 쟁점만 공급업체/공식 상담에 확인할 수 있음.
- 과거 준비한 공급업체 문의는 승인되지 않아 미발송. 이번에도 외부 메일을 보내지 않음.

### 3. 보관·복원 절차를 시행 가능한 상태로 확정

- 로컬 백업 기준 30일: `expire-local-backups.ps1`을 준비하고 백업 성공 뒤 연결. 실제 예약은 없으므로 매일 수동 만료 점검 또는 별도 승인된 예약 구성이 필요. USB를 복사하면 동일 기준으로 삭제하며 분리 사본을 무기한 두지 않음.
- 삭제/탈퇴/정정 요청을 백업 이후에도 추적할 최소 기록과, 격리 복원 후 재적용 확인 절차를 확정. 현재 통합 복원 시험은 정상 탈퇴 동기화를 확인했으나 과거 요청 전체 재적용 자동화 시험은 아님.
- 이 보고서의 운영자 네 필드 삭제를 첫 재적용 사례로 남김. 다른 회원을 조회·삭제하는 시험을 하지 않음.
- 탈퇴 차단 해시의 기간은 현재처럼 운영 기간 보관이 정말 필요한지 요청 유효기간·재시도 경계와 함께 재설계 검토. 단순 만료만 넣어 늦은 쓰기를 다시 허용하지 않음.
- 문의 메일·장기 미해결 제보는 자동 정리라고 안내하지 않고 실제 수동 운영 항목으로 관리.

- 보관 정리: 완료 문의 30일, 해결 제보 30일, 로컬 백업 30일 기준을 각각 점검. 권리 요청/법적 보존에 필요한 예외는 근거·항목·기간을 별도 관리하고 전체 데이터를 무기한 보존하지 않는다.
