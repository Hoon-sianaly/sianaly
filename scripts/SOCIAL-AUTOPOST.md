# 매일 인스타 카드뉴스 자동으로 올리기

시애널리 자료로 **매일 인스타 카드뉴스 2개**를 만들어요. 프로그램이 **스스로 2번 검토한 뒤** 자동으로 올려요.
드는 돈은 **0원**이에요. GitHub 자동 실행과 인스타 올리기 기능이 모두 무료예요.

| 시각 (한국) | 내용 |
|---|---|
| 매일 오전 6:30 | 랜덤으로 고른 기업 하나 |
| 매일 오후 6:30 | 랜덤으로 고른 기업 하나 |

- 최근 90일 안에 올린 기업은 빼고 골라요. 그래서 아침과 저녁 기업이 겹치지 않아요.
- 우선주처럼 실적 자료가 따로 없는 종목, 분기 실적이 4개보다 적은 기업은 고르지 않아요.
- 카드뉴스는 6장(1080×1350)이에요. 표지 → 하는 일 → 최근 분기 숫자 → 5분기 그래프 → 한 줄 정리 → 사이트 안내 순서예요.
- 숫자는 사이트가 쓰는 코드(`company-data.js`)로 만들어요. 그래서 **사이트에 나오는 숫자와 똑같아요.**
- 인스타 계정: **sianaly_ins**

> 지금 꺼 둔 기능 두 가지
> - **네이버 블로그 초안**: 네이버는 자동으로 글을 올리는 기능을 2020년에 없앴어요. 그래서 다 만든 초안을 GitHub 알림(이슈)으로 보내는 기능을 만들어 두었어요. 지금은 꺼져 있어요.
>   다시 켜려면 저장소 **Settings → Secrets and variables → Actions → Variables** 탭에서 `BLOG_DRAFTS` 이름으로 `on`을 넣으면 돼요.
> - **새 실적 고르기**: 공시로 새로 나온 실적을 고르는 기능도 남아 있어요. 지금은 쓰지 않아요.
>   다시 쓰려면 `.github/workflows/social-daily.yml`의 만들기 줄에 `--topic earnings`를 붙이면 돼요.

## 1. 스스로 2번 검토하기

올리기 전에 아래 두 검토를 모두 통과해야만 올라가요. 하나라도 틀리면 인스타에 올리지 않아요. 그리고 작업을 "실패"로 표시해서 GitHub가 메일로 알려 줘요.

**1차 검토 (내용)** — `scripts/social/review-posts.cjs`
- 그림에 나온 숫자를 **원본 기업 파일에서 다시 하나하나 찾아서** 같은지 확인해요. 한 번에 30개쯤 봐요.
- "늘었어요 / 줄었어요 / 흑자로 돌아섰어요" 같은 표현이 실제 숫자와 맞는지 다시 계산해요.
- 그림에 깨진 글자(undefined 등)가 없는지, "투자 권유 아님" 안내가 들어갔는지 확인해요.
- 인스타 글이 2200자 이하인지, 해시태그가 30개 이하인지 확인해요.

**2차 검토 (파일)**
- 카드 그림 6장이 모두 있는지, 크기가 1080×1350인지, 용량이 8MB 이하인지 확인해요.

검토 결과는 GitHub **Actions** 화면에서 그날 작업을 누르면 ✅/❌ 목록으로 볼 수 있어요. 맨 아래 "올리기 결과"에 올라간 인스타 글 주소도 나와요.

## 2. 인스타 계정과 키 (처음 한 번 — 이미 해 두었어요)

새로 만들어야 할 때를 위해 순서를 남겨 둬요.

### 인스타 계정
1. 인스타 앱에서 계정을 만들어요.
2. **프로필 → ☰ 메뉴 → 계정 유형 및 도구 → 프로페셔널 계정으로 전환**에서 **비즈니스**를 골라요.
   - 개인 계정은 자동으로 올릴 수 없어요.

### 메타 앱과 키
1. [developers.facebook.com](https://developers.facebook.com) → 로그인 → 개발자 가입
2. **비즈니스 포트폴리오**를 만들어요 (이름: `Sianaly`). 메타가 앱을 만들 때 요구해요.
3. **내 앱 → 앱 만들기** → 사용 사례 **"Instagram에서 메시지 및 콘텐츠 관리"** → 앱 이름 `sianaly-social`
4. 앱의 **Instagram API(통합 로그인)** 화면에서 **구성**을 하나 만들어요.
   - 토큰 만료: **만료되지 않음**
   - 권한: `instagram_basic`, `instagram_content_publish` (메시지 권한은 함께 들어가도 괜찮아요)
5. 앱 **역할 → 사람 추가**에서 인스타 계정을 **Instagram 테스터**로 넣어요. 그다음 인스타 앱 **설정 → 앱 및 웹사이트**에서 초대를 수락해요.
6. **액세스 토큰 생성**에서 인스타 계정을 연결하고 토큰을 만들어요.
   - 나온 긴 글자(키)를 GitHub에 `IG_ACCESS_TOKEN`으로 넣어요. 지금 키는 **"EA"로 시작**하는 종류예요.
   - 같은 화면 계정 옆의 긴 숫자("1784…"로 시작)가 **인스타 계정 번호**예요. GitHub에 `IG_USER_ID`로 넣어요.
7. 앱은 **개발 모드 그대로** 둬도 돼요. 우리 계정에만 올리니까 검수 신청은 필요 없어요.

> 키는 "IG"로 시작하는 것과 "EA"로 시작하는 것, 두 종류가 있어요. 올리기 프로그램이 둘 다 알아서 맞춰 써요.
> "EA" 키는 계정 번호를 스스로 못 찾을 때가 있어서 `IG_USER_ID`를 **꼭** 넣어야 해요.

### 인스타 하루 한도와 키 기간
- 자동으로 올릴 수 있는 건 **24시간에 100개**예요 (카드뉴스 1개가 1개). 우리는 하루 2개라 넉넉해요. 올리기 전에 남은 한도를 먼저 확인해요.
- 키는 "만료되지 않음"으로 만들었어요. 그래도 비밀번호를 바꾸거나 메타가 권한을 다시 확인하면 키가 막힐 수 있어요.
  그날 작업이 "인스타 키로 계정을 확인하지 못했어요"라며 실패하면, 위 6번대로 키를 새로 받아 `IG_ACCESS_TOKEN`만 바꿔 주세요.
- 인스타는 그림을 **인터넷 주소**로만 받아 가요. 그래서 그날 카드 그림을 이 저장소의 `social-posts` 브랜치에 잠깐 올려 두고, 그 주소를 인스타에 알려 줘요.
  최근 20번 것만 남기고 오래된 그림은 자동으로 지워요. 사이트(`main`)와는 상관없어요.

## 3. GitHub Secrets에 키 넣기

키는 **절대 파일이나 코드, 채팅에 적지 말고** 아래 금고에만 넣어요. 넣은 뒤에는 누구도(본인도) 다시 볼 수 없고, 프로그램만 써요.

1. [github.com/Hoon-sianaly/sianaly](https://github.com/Hoon-sianaly/sianaly) → **Settings**
2. 왼쪽 **Secrets and variables → Actions**
3. **New repository secret** → Name에 이름, Secret에 값 붙여넣기 → **Add secret**
   - 이미 있는 값을 바꿀 때는 그 이름 옆 연필 버튼을 눌러요.

| 이름 | 값 | 꼭 필요? |
|---|---|---|
| `IG_ACCESS_TOKEN` | 메타에서 받은 키 ("EA…") | 꼭 |
| `IG_USER_ID` | 인스타 계정 번호 ("1784…") | 꼭 ("EA" 키일 때) |

- 키가 없으면 카드뉴스를 만들고 검토까지만 해요. 인스타에는 올리지 않아요.

## 4. 직접 실행하기

GitHub → **Actions → Daily social posts → Run workflow**에 선택지가 3개 있어요.

| 선택지 | 뜻 |
|---|---|
| 어느 순서를 만들까요? | `auto` = 지금 시각 기준 (낮 12시 전이면 아침, 후면 저녁). `morning`/`evening`으로 정할 수도 있어요. |
| 실제로 올릴까요? (upload) | 끄면 만들고 검토만 해요. 켜면 인스타에 올려요. |
| 이미 올린 순서라도 다시 올릴까요? (force) | 그날 그 순서를 이미 올린 기록이 있어도 다시 만들어 올려요. **올리기가 실패해서 다시 시도할 때만** 켜요. |

- 만든 카드 그림은 작업 화면 아래 **Artifacts**에서 내려받아 볼 수 있어요 (7일 보관).
- **주의**: 직접 실행으로 그날 아침 순서를 올리면, 그날 06:30 예약 실행은 "이미 올렸어요" 하고 건너뛰어요.

## 5. 알아 두면 좋은 것

- **예약 시각**: GitHub 예약은 가끔 늦게 시작해요. 그래서 40분 일찍(05:50, 17:50) 만들기 시작하고, 정해진 시각까지 기다렸다가 올려요. 아주 붐비는 날은 몇 분 늦을 수 있어요.
- **예약은 `main`에 있는 것만 돌아요**: 올리기 프로그램을 고치면 `main`에 합쳐야 다음 예약부터 바뀐 대로 돌아요. 바뀌는 건 자동 올리기 프로그램뿐이고, 사이트 화면은 그대로예요.
- **같은 걸 두 번 올리지 않아요**: 무엇을 올렸는지 `social-posts` 브랜치의 `state.json`에 적어 둬요.
- **실패하면**: GitHub가 메일로 알려 줘요. Actions 화면에서 그날 작업을 열면 맨 아래 "올리기 결과"에 이유가 한국어로 나와요.
- **Cloudflare**: `social-posts` 브랜치에 그림이 올라갈 때마다 Cloudflare가 "미리보기 사이트"를 하나씩 만들 수 있어요. 무료 한도 안이라 돈은 안 들어요.
  신경 쓰이면 Cloudflare Pages → 설정 → 빌드 → **브랜치 제어**에서 `social-posts`를 빼 주세요.
- **멈추고 싶을 때**: GitHub → Actions → Daily social posts → 오른쪽 위 `…` → **Disable workflow**
- **내 컴퓨터에서 미리보기**: Chrome이나 Edge만 있으면 카드 그림을 만들어 볼 수 있어요 (PNG로 만들어요).
  ```bash
  node scripts/social/make-posts.cjs --slot morning --preview --out output/social
  ```
  ```bash
  node scripts/social/review-posts.cjs output/social/<날짜>-morning --preview
  ```

## 파일 설명
| 파일 | 하는 일 |
|---|---|
| `scripts/social/make-posts.cjs` | 기업 고르기 → 카드 그림 6장 + 인스타 글 만들기 |
| `scripts/social/slides.cjs` | 카드 화면 디자인 |
| `scripts/social/review-posts.cjs` | 1차(내용)·2차(파일) 검토 |
| `scripts/social/upload-instagram.cjs` | 인스타 카드뉴스 올리기 (두 종류 키 모두 지원) |
| `scripts/social/finish.cjs` | 정해진 시각까지 기다리기, 올린 기록 남기기 |
| `scripts/social/push-store.sh` | 올린 기록·카드 그림을 `social-posts` 브랜치에 저장 |
| `scripts/social/blog.cjs`, `post-blog-draft.cjs` | 네이버 블로그 초안 (지금은 꺼 둠) |
| `.github/workflows/social-daily.yml` | 매일 예약 실행 |
