드는 돈은 **0원**이에요. (GitHub 자동 실행, 인스타 올리기 기능 모두 무료)

| 시각 (한국) | 내용 | 만들어지는 것 |

- 숫자는 사이트가 쓰는 코드(`company-data.js`)를 그대로 써서 만들기 때문에, **사이트에 나오는 숫자와 똑같아요.**

## 1. 스스로 2번 검토하기

올리기 전에 아래 두 검토를 모두 통과해야만 올라가요. 하나라도 틀리면 **인스타에 올리지도, 블로그 초안을 보내지도 않고** 작업을 "실패"로 표시해요. (GitHub가 메일로 알려 줘요.)

**1차 검토 (내용)** — `scripts/social/review-posts.cjs`
- 그림에 나온 숫자를 **원본 기업 파일에서 다시 하나하나 찾아서** 같은지 확인 (한 번에 30개 정도)
- "늘었어요 / 줄었어요 / 흑자로 돌아섰어요" 같은 표현이 실제 숫자와 맞는지 다시 계산
- 저녁 실적은 실제로 오늘 공시 목록에 있는 기업·분기인지 확인
- 그림에 깨진 글자(undefined 등)가 없는지, "투자 권유 아님" 안내가 들어갔는지
- 블로그 글의 분기별 숫자가 그림과 같은지, 블로그 제목 60자·인스타 글 2200자·해시태그 30개 같은 규칙

**2차 검토 (파일)**
- 카드 그림이 6장 모두 있고, 크기가 1080×1350, 용량이 8MB 이하인지
- 블로그 글에 넣을 그림이 빠짐없이 있는지

검토 결과는 GitHub의 Actions 화면에서 그날 작업을 누르면 ✅/❌ 목록으로 볼 수 있어요.

## 2. 계정 만들기 (처음 한 번)

### 네이버 블로그
1. 쓰고 싶은 네이버 아이디로 [blog.naver.com](https://blog.naver.com) 로그인 → **내 블로그** → 블로그 이름(예: 시애널리 실적 노트) 정하기
2. 따로 키를 받거나 GitHub에 넣을 것은 **없어요.** 네이버 비밀번호도 어디에도 넣지 않아요.

### 인스타그램
1. 인스타 앱에서 새 계정 만들기 (예: sianaly)
2. **프로필 → ☰ 메뉴 → 계정 유형 및 도구 → 프로페셔널 계정으로 전환**
3. **크리에이터** 또는 **비즈니스** 중 하나 선택 (둘 다 자동 올리기 가능. 고민되면 "크리에이터")
   - 개인 계정은 자동으로 올릴 수 없어요.
   - 페이스북 페이지는 필요 없어요.

## 3. 네이버 블로그 초안 받아서 올리기 (매일 2번, 약 2분)

1. 06:30, 18:30쯤 GitHub에서 **"[블로그 초안] 날짜 기업이름"** 알림이 와요. (메일 또는 GitHub 앱)
   - 알림을 받으려면 GitHub 저장소 오른쪽 위 **Watch → All Activity**를 켜 두세요. 휴대폰에 GitHub 앱을 깔면 바로 알림이 떠요.
2. 알림(이슈)을 열면 순서대로 있어요.
   - **① 제목**: 복사 → 네이버 글쓰기 제목 칸에 붙여넣기
   - **② 블로그 본문**: "여기부터 끝까지"를 드래그해서 복사 → 본문에 붙여넣기
   - 그림이 빠져서 붙으면, 알림 위쪽 **카드 그림 내려받기** 링크 → 아래쪽 **Artifacts**에서 내려받아 그림을 끌어다 넣어요.
   - **③ 태그**: 태그 칸에 넣기
3. **발행** → 그 알림(이슈)의 **Close issue**를 눌러 "다 올렸음"으로 표시
- 시간이 없으면 네이버 글쓰기의 **예약 발행**으로 원하는 시각을 정해 둬도 돼요.
- 컴퓨터로 받으면 Artifacts 안 `blog.html`을 열어 **제목 복사 / 본문 복사 / 태그 복사** 버튼으로 더 쉽게 옮길 수 있어요.

## 4. 인스타 키 받기 (처음 한 번, 약 15분)

준비물: 위에서 만든 **프로페셔널(크리에이터/비즈니스)** 인스타 계정, 페이스북 계정(개발자 가입용).

1. [developers.facebook.com](https://developers.facebook.com) → 로그인 → **시작하기**로 개발자 가입
2. **내 앱 → 앱 만들기**
   - 사용 사례: **"Instagram에서 메시지 및 콘텐츠 관리"** 선택
   - 앱 이름 `sianaly-social` → 만들기
3. 앱 화면 왼쪽 **사용 사례 → Instagram API → API 설정(Instagram 로그인)**
4. **"액세스 토큰 생성"** 칸에서 **계정 추가** → 인스타 계정으로 로그인 → 허락
   - 권한에 `instagram_business_basic`, `instagram_business_content_publish`가 들어 있어야 해요.
   - "테스터로 초대" 단계가 나오면, 인스타 앱 **설정 → 앱 및 웹사이트 → 테스터 초대**에서 수락해요.
5. 계정 옆 **토큰 생성** → 나온 긴 글자(액세스 토큰) 복사 → GitHub에 `IG_ACCESS_TOKEN`으로 넣기
   - 같은 화면에 나오는 숫자 **Instagram 사용자 ID**는 `IG_USER_ID`로 넣어도 되고, 안 넣어도 자동으로 찾아요.
6. 앱은 **개발 모드 그대로** 둬도 돼요. 본인 계정에만 올리니까 검수 신청은 필요 없어요.

### 인스타 하루 한도와 키 기간
- 자동으로 올릴 수 있는 건 **24시간에 50개**(카드뉴스 1개 = 1개)예요. 우리는 하루 2개라 넉넉해요. 올리기 전에 프로그램이 남은 한도를 먼저 확인해요.
- 인스타 키는 **60일** 뒤에 만료돼요. **50일쯤마다** 4번의 "토큰 생성"을 다시 눌러 새 키로 바꿔 주세요. 깜빡하면 그날 작업이 "인스타 키가 만료됐어요"라고 실패로 알려 줘요.
- 인스타는 그림을 **인터넷 주소**로만 받아 가요. 그래서 그날 카드 그림을 이 저장소의 `social-posts` 브랜치에 잠깐 올려 두고, 그 주소를 인스타에 알려 줘요. 10일 지난 그림은 자동으로 지워요. (사이트 `main`과는 상관없어요.)

## 5. GitHub Secrets에 키 넣기

키는 **절대 파일이나 코드에 적지 말고**, 아래 금고에만 넣어요. 넣은 뒤에는 누구도(본인도) 다시 볼 수 없고 프로그램만 써요.

1. [github.com/Hoon-sianaly/sianaly](https://github.com/Hoon-sianaly/sianaly) → **Settings**(설정)
2. 왼쪽 **Secrets and variables → Actions**
3. **New repository secret** → Name에 이름, Secret에 값 붙여넣기 → **Add secret**
4. 아래를 하나씩 반복:

| 이름 | 값 | 꼭 필요? |
|---|---|---|
| `IG_ACCESS_TOKEN` | 4-5번의 액세스 토큰 | 인스타 올릴 때 |
| `IG_USER_ID` | 4-5번의 Instagram 사용자 ID | 선택 |

- 네이버 블로그는 넣을 키가 없어요. 블로그 초안 알림은 GitHub가 원래 주는 권한으로 보내요.
- 인스타 키를 아직 안 넣었으면, 인스타는 **만들고 검토까지만 하고 올리지 않아요.** 블로그 초안은 그래도 와요.

## 6. 처음 켜는 순서

1. **이 파일들이 `main`에 들어가야 예약 실행이 돌아요.** (GitHub는 기본 브랜치에 있는 예약만 실행해요.)
   - 새로 생긴 파일: `.github/workflows/social-daily.yml`, `scripts/social/` 폴더, 이 안내서
   - 사이트 화면은 하나도 안 바뀌어요. 그래도 규칙대로 `codex/dev`에서 먼저 확인한 뒤 `main`에 합쳐 주세요.
2. GitHub → **Actions → Daily social posts → Run workflow**
   - "실제로 올릴까요?"는 **끈 채로** 실행 → 만들고 2번 검토만 해요.
   - 끝나면 그 작업 화면 아래 **Artifacts**에서 `social-...` 파일을 내려받아 카드 그림과 `blog.html`(블로그 초안)을 직접 확인해요.
3. 마음에 들면 5번대로 키를 넣고, 한 번 더 **Run workflow**를 "실제로 올릴까요?" **켜고** 실행해 봐요.
4. 그다음부터는 매일 06:30, 18:30에 인스타는 알아서 올라가고, 블로그 초안 알림이 와요.
   - GitHub 예약은 가끔 늦게 시작해요. 그래서 40분 일찍(05:50, 17:50) 만들기 시작해서 정해진 시각까지 기다렸다가 올려요. 아주 붐비는 날은 몇 분 늦을 수 있어요.

## 7. 알아 두면 좋은 것

- **Cloudflare**: `social-posts` 브랜치에 그림이 올라갈 때마다 Cloudflare가 "미리보기 사이트"를 하나씩 만들 수 있어요(무료 한도 안이라 돈은 안 들어요). 신경 쓰이면 Cloudflare Pages → 설정 → 빌드 → **브랜치 제어**에서 `social-posts`를 빼 주세요.
- **같은 걸 두 번 올리지 않아요**: 무엇을 올렸는지 `social-posts` 브랜치의 `state.json`에 적어 둬요.
- **멈추고 싶을 때**: GitHub → Actions → Daily social posts → 오른쪽 위 `…` → **Disable workflow**.
- **내 컴퓨터에서 미리보기**: Chrome이나 Edge만 있으면 카드 그림과 블로그 초안을 만들어 볼 수 있어요.
  ```bash
  node scripts/social/make-posts.cjs --slot evening --preview --out output/social
  ```
  ```bash
  node scripts/social/review-posts.cjs output/social/<날짜>-evening --preview
  ```
